# 基本设定重构计划

## 目标

- 删除独立“站点”步骤，把站点目录、站点选择、强迫场文件和建算例入口并入“基本设定 / 文件与目录”。
- “基本设定”在左侧工作流展开子步骤：文件与目录、站点信息、时间与预热、网格与并行、地表数据、初始场、强迫场。
- 城市过程移入过程参数，只在 URBAN 配置下出现；未启用的示踪剂等空分栏自动隐藏。
- “过程参数”在左侧展开水热、生态生地化、河道水库、数据同化、示踪剂、城市过程；删除无意义的“其他”。
- 基本设定与过程参数使用原生折叠组，启动时默认收起。

## 行为约束

- 文件与目录页在没有算例时仍能扫描站点、选择产物目录并建算例。
- 算例目录位于站点选择卡下方的独立卡片；不再重复显示算例文件字段表。
- 站点列表按向导的 URBAN 选择过滤，城市配置只见城市站，自然配置只见自然站。
- 建好算例后，各子步骤继续复用现有批量编辑、类型校验和不一致提示。
- 所有子步骤由页面底部的“上一步 / 下一步”顺序连接，不再另放横向标签。
- 时间范围只读自强迫场；预热仍按每个算例自己的起始时刻计算。
- 运行页的输出与重启、输出变量归属不变。

## 验证

- 静态测试锁定左侧嵌套流程、前后连接和字段唯一归属。
- 运行 workspace、GUI 测试与 Clippy。
- 启动 GUI，确认前端加载、后端与 sidecar 均可达。
