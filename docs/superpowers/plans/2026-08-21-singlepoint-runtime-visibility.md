# 单点运行时参数可见性重构计划

**目标：** 单点算例只显示在当前内核、站点类型和过程开关下真正有效的参数；
父选项变化后立即刷新子字段，避免用户配置被 CoLM 强制覆盖或进入不可达分支。

**行为边界：** 不改变 case.nml 的已有值，不删除用户配置；这里只改变 GUI 的显示、
禁用状态和可选值。区域/全球尚未开放，现阶段规则必须以 `SinglePoint` 为主，同时保留
非单点内核的原有编译期过滤。

## 实施顺序

- [x] 在 Rust 配置层增加统一的 `field_states`：组合内核宏、case.nml 当前值、
      次网格/土壤/BGC/CROP/URBAN/TRACER/LULCC、站点地类和父开关。
- [x] 先用表驱动回归测试锁定自然 LCT、PFT+BGC、PC、城市、湖泊/湿地、初始化、
      强迫降尺度、VIC runoff、SinglePoint 输出和高光谱约束。
- [x] 前端参数页只消费后端返回的 `hidden/disabled/editable` 状态，不再维护城市特例表。
- [x] 任意父字段保存后重新读取并渲染，保证子字段即时出现/消失。
- [x] 对完整/简单降尺度实施互斥可选值，阻止生成两个开关同时为真的新配置。
- [x] 隐藏 SinglePoint 向导里的 `SrfdataDiag`，因为 CoLM 会无条件关闭它。
- [x] 批量编辑按全部算例合并有效性并标出差异，不再用第一个站点代表整批。
- [x] 运行时状态计算失败时关闭参数展示，避免回退后重新暴露无效字段。
- [x] 运行 GUI Rust 测试、前端测试、xtask 静态检查、构建和真实窗口冒烟测试。

## 验收条件

1. 当前自然 LCT+VG 单点算例至少隐藏审核中确认的 46 个无效字段。
2. 初始化、降尺度、VIC、SNICAR、臭氧等子字段只在父开关成立时显示。
3. SinglePoint 不再出现区域地表、网格历史输出、TOPMOD、固定插值方案等无效项。
4. 城市、BGC、CROP、Tracer、高光谱字段严格跟随运行时和编译期能力。
5. 改变父字段不会改写无关字段；旧配置即使含隐藏字段也保持原样。
