# 强迫场缺测诊断、插值与 ERA5-Land 补全实施计划

## 目标

在“前处理 → 强迫场”中增加一条可审计的数据修复流水线：

1. 先诊断被映射到 CoLM 八个槽位的变量；
2. 短缺口按变量物理类型做局部插值；
3. 长缺口按站点位置读取 ERA5-Land 对应格点；
4. 将源文件时间转换到 UTC 后对齐 ERA5-Land；
5. 仅用同时存在的站点观测与 ERA5-Land 样本估计偏差订正；
6. 写出新的“已修复中间文件”，再交给现有 `forcing-convert` 标准化。

原始文件永不覆盖。每个修复值都带质量标记，文件级属性记录时区来源、
ERA5-Land 来源、阈值与订正方法。

## 非目标与安全边界

- 不把科学修复塞入现有格式转换器；`forcing-convert` 仍只做映射、合并和单位换算。
- 不把“按经度得到的 UTC 偏移”伪装成 IANA 时区。它只叫
  `longitude_inferred_offset`，界面必须允许人工覆盖。
- 不静默重采样不规则时间轴。源时间轴不均匀时阻断修复并指出原因。
- 不在线传输 CDS API token。下载器只调用用户本机的 Python `cdsapi` 与
  `~/.cdsapirc`；缺少凭据或未接受许可时给出可操作错误。
- 不对累计量直接线性插值。ERA5-Land 的累计降水/辐射先转换成时段平均率。
- 校准重叠样本不足时不声称“已订正”；长缺口保持未解决并阻断标准化。

## 分层

### 1. `colm-forcing::gapfill`（纯算法与 NetCDF 修复）

- `diagnose`: 缺测总数、连续缺口、最长缺口、短/长分类；
- `timezone`: 明确元数据 / 人工覆盖 / 经度推断，并记录来源；
- `interpolate`: 连续状态量线性插值；降水只在两端都为零时补零；
- `era5`: 最近格点、UTC 对齐、露点转比湿、累计量转率；
- `bias`: 月尺度加性或乘性订正，月样本不足时回退全期样本；
- `repair`: 复制原文件、替换被选变量的缺测值并增加 `<var>_gapfill_qc`。

质量标记：

| 值 | 含义 |
|---:|---|
| 0 | 原始观测 |
| 1 | 短缺口插值 |
| 2 | ERA5-Land 偏差订正后补全 |
| 9 | 未解决缺测 |

### 2. `colm-cli`

- `forcing-gap-probe <src> --slot ...`: 返回 JSON 诊断和时区判定；
- `forcing-repair <src> <dst> --slot ...`: 生成修复后的中间文件；
- `era5land-download <dir> ...`: 通过官方 `cdsapi` 下载站点最近 0.1° 格点。

### 3. Tauri 与前端

窗口进程继续不链接 NetCDF，只调用 `colm-cli` sidecar。强迫场页在“时间轴”与
“转换”之间增加“缺测诊断与修复”卡片，展示：

- 每个槽位的缺测数和最长缺口；
- 短缺口阈值；
- 时区判定来源、UTC 偏移与人工覆盖；
- 站点经纬度；
- ERA5-Land 本地缓存目录、下载按钮；
- 修复后各来源计数和未解决数。

只要存在未解决长缺口，“转换”按钮保持禁用。

## 变量方法矩阵

| CoLM 槽位 | 短缺口 | ERA5-Land 来源 | 偏差订正 |
|---|---|---|---|
| 气温 | 线性 | `t2m` | 加性（月均差） |
| 比湿 | 线性、非负 | `d2m + sp` 推导 | 加性、非负 |
| 气压 | 线性 | `sp` | 加性 |
| 降水 | 两侧均为零才补零 | `tp` 时段率 | 乘性、非负 |
| 东/北风 | 线性 | `u10` / `v10` | 加性 |
| 短波/长波 | 线性、非负 | `ssrd` / `strd` 时段率 | 乘性、非负 |

默认短缺口阈值为 3 个时间步。阈值在界面可改，所有方法与阈值写入产物属性。

## 验收

- 纯算法单测覆盖短/长缺口、边界缺口、非负约束、最近格点、经度环绕、
  时区优先级、UTC 对齐、加性/乘性订正与样本不足。
- NetCDF 夹具验证源文件不变、修复文件值、QC 变量和 provenance 属性。
- CLI 夹具验证无 ERA5 时短缺口可离线修复、长缺口会阻断、提供本地 donor 后可修复。
- GUI 静态契约测试验证命令、控件和“未解决长缺口阻断转换”。
- 运行 Rust workspace 测试、GUI/Tauri 测试、Clippy、格式检查及应用启动探针。
