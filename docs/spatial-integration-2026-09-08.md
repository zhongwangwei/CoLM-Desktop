# Spatial 整合与站点回归（2026-09-08）

用户在独立分支审计完成后授权 spatial 合入 main。本次整合保留 main `9553990` 与 spatial `98c7de2` 的历史和共用修复，不使用整文件覆盖来跳过 main 的校验。

## 使用边界

- 流域、区域、全球及经纬度、非结构、流域网格，连同空间内核选项，统一标记 **early state（早期阶段，不建议使用）**；中文、英文、空间配置页和 CLI 都有提示。
- 空间模式不能创建、启动、重试、恢复或应用参数调优/不确定性分析。界面和 CLI 共同限制，旧 Study 也不能绕过。
- 暂停、取消和只读状态/导出仍保留，避免失去已有任务的安全收尾入口。切换模式不擅自杀死正在运行的进程；尚未发起的旧队列操作停止派发。
- 站点模式仍为推荐路径；切回站点后可以进入调优和不确定性分析，原有参数/观测/预算就绪条件仍然有效。
- 不更新版本、发布内核、安装包、原始 rawdata/runtime 或科学 golden；源码整合不代表现有 Beta 安装包已经包含这些功能。

## 合并期间发现并修复的问题

1. **站点模板误判为空间**：直接匹配 `DEF_domain%` 或 mesh 字段名会把注释、空值、`null` 和完整模板的默认占位路径当成空间算例。改用共用 Rust namelist 解析和已有默认值判定；Tauri `CaseEntry.spatial` 提供真实元数据，GUI 不再猜测文本。实际 red/green 覆盖模板默认路径误判。
2. **旧空间建例回复污染站点任务**：捕获项目路径、算例名、配置内容及向导对象身份；异步返回后检查再更新列表/当前算例，已落盘但失效的结果不注入新任务。
3. **旧 Study 回复启动新任务**：每次延迟的 run/retry/resume/apply 操作之前和关键返回点检查范围与内核；防止旧 retry 完成后自动启动新范围的 Study。保留站点正常路径的正向测试。
4. **只有 GUI 隐藏仍可绕过**：共用后端限制空间网格路径和非 SinglePoint 内核，覆盖预检、创建、启动、重试、恢复、应用和应用预览；限制发生在 checkpoint、控制标记或应用输出变更之前。
