# 不确定性分析与参数调优

CoLM Desktop 的这两项功能是“结果分析”中的相邻工作流，共用同一套 Study、参数注册表、成员调度、指标与导出格式。Rust `colm-cli` 是唯一权威引擎；GUI 只创建规格、显示状态和请求聚合结果。

## 概念边界

- **不确定性分析**回答：在用户确认的参数范围内，模型输出会变化多少，哪些参数影响最大。支持单因素双端扫描（OAT）、Latin hypercube sampling（LHS）和 Morris 筛选。观测可选：
  带了目标（`targets` + `observations`，只用一个时段、不设验证期）时，每个成员还要算目标函数，`importance.json` 多出 `variable: "objective"`（`site: null`）的一组，回答"调这个参数能不能让拟合变好"。GUI 默认勾选"对照观测算目标函数"，结果页按它排序，选中的参数可以"带入率定"（同样的算例、观测、指标，范围用不确定性研究冻结的）。
- **参数调优**回答：在固定站点、变量、质量控制和连续时间窗上，哪组参数最小化预先声明的目标。V1 使用批量差分进化（DE），需要观测。
- 样本 P05/P50/P95 是有限参数样本下的**样本分位带/情景范围**，不是统计置信区间。
- 参数范围表示用户愿意检验的科学假设，不是由软件猜出的物理先验。当前注册字段全部标为“仅专家范围”。
- GUI 勾选参数时预填默认值的 0.5–1.5 倍（夹进目录硬边界，开区间往里收 1%），界面写明这只是起点、不是物理先验；
  用户按文献或观测改过后，须勾选"已核对参数范围、预算和适用范围"才能创建研究。研究报告最优值贴边界时提示放宽。
  （原来写"普通模式不提供猜测的默认范围"，与第 744 轮加的预填冲突；2026-10-23 定为保留预填、明示其性质。）
- 空间模式（格点算例：流域/区域/全球）已支持率定与不确定性分析（2026-10-21 起）：目标可以是格点观测产品、
  区域里的通量站或水文站流量；不确定性研究也按同一目标函数排序。它比单点重得多（一次研究是几十到上百个
  格点算例），先在小区域上确认设计再放大。
- 现有"留一站"结果只是**重排诊断**，不是交叉验证：候选来自全站综合损失的差分进化，留出站已参与候选生成，
  所以它不能证明对未参与率定站点的泛化。真正的留站/留年/留气候区分折训练尚未提供。

## 可复现性合同

1. Study 创建前验证参数白名单、有限边界、log 正值、跨字段硬约束、算例根目录和目标。
2. 同一 seed、参数 ID 和规格生成相同的 OAT/LHS 设计。baseline 独立保存，不进入集合分位数或相关性。
   DE 规格写了 `budget.include_baseline: true`（GUI 新建的研究都写）时，初代评完后 baseline 若可行、
   严格好于最差的初代成员、且每个参数都在抽样范围内，就顶替那个成员成为父代；被顶替的成员不再重试。
   baseline 仍不算"最优候选"：`best_member` 只在非 baseline 成员里选。
3. OAT/LHS 使用不可变 `samples/design.csv`；DE 每代追加不可变 `samples/gNNNNNN.csv`。恢复不重新抽样。
4. 每个 member/site 使用独立 `DEF_CASE_NAME` 和输出目录，并完整运行 `mksrfdata -> mkinidata -> colm`。原算例只读。
5. 状态写入带哈希链的不可变 checkpoint。损坏的最高代会回退到上一份有效状态。
6. 固定输入、站点、强迫场、观测、过程参数、内核和样本行都进入 manifest/运行指纹。创建 Study 必须绑定已验证内核，运行时不能换用其他内核。
7. DE 初代样本由 manifest 哈希冻结，后续每个 `gNNNNNN.csv` 有独立不可变 SHA-256 记录；续跑和导出前都会验证。

### 预处理后端

`study-run` 与普通 `run` 一样默认使用 Rust `mksrfdata-rs`、`mkinidata-rs`；
模型积分仍使用所绑定内核的 `colm.x`。保留原版预处理可显式指定
`--preprocessors fortran`。缺少 Rust 可执行文件会在派发任务前报错，不静默回退。

阶段指纹包含后端和 Rust 预处理器的完整 SHA-256。更换 surface 程序使三阶段
失效；只更换 initial 程序使 initial 和积分失效。不变的程序与输入才可复用产物。
切换后端或更新程序后，已完成选择的 DE 历史代不会被重写，须创建新 Study。
历史指纹不包含这些哈希时也按失效处理，而不是认定旧产物仍然有效。

Study 尚未接入 Rust HYPERSPECTRAL 外部输入的冻结与指纹，默认 Rust 模式会在
派发前拒绝该组合；此类 Study 暂用 `--preprocessors fortran`。这不改变普通
`run` 已有的高光谱输入接口，也不代表所有科学模式已经通过迁移验收。

参数目录版本为 2：连续采样不再包含只接受整数日的 `DEF_TUNING_CROP_PLANTING_DAY`（仍可手工编辑），有正值定义域的参数可使用合法的正数 log 子区间。灌溉持续时间范围不能短于算例的模型时间步长。目录版本 1 的 Study 需要以新版本重新创建；旧文件不删除，也不静默改写冻结规格。缺少版本信息的历史规格仍须通过当前校验。

## 目标函数

普通模式默认最小化：

```text
NRMSE = RMSE / observation_sample_sd
objective = sum(frozen_weight_i * loss_i) / sum(frozen_weight_i)
```

- `min_pairs` 规格缺省为 30；GUI 预填 20。观测标准差为零或非有限时目标无效。
- 多变量、多站点先分别归一化，再按创建时冻结的权重合并。
- 每个目标的权重和 `min_pairs` 都保存在 Study spec 中；创建后不会随 GUI 当前值变化。
- 任一必需校准目标缺失、指标非有限或配对不足，整个候选为 infeasible（数学上为 `+∞`）；绝不删除困难目标后重新归一化。
- 同站点、目标和窗口的候选必须与 baseline 使用相同的配对时间和观测值；结果记录配对数量与支持集哈希，不把候选缺失的时刻静默移出评分问题。
- 专家目标 MAE、绝对 Bias、NSE、KGE、R² 和 r 都转换为“越小越好”的损失。效率/相关类使用 `1 - metric`。
- R² 指 Pearson r 的平方，不是预测决定系数；平方会丢失相关方向。KGE 使用 2009 形式，NRMSE 的分母使用配对观测的样本标准差。
- 校准与验证使用连续、互不重叠的 `[from,to)` UTC/模型时间窗口，不随机打乱时间点。
- GUI 预填窗口（`suggestedWindows`）：从 history 正式起点算起；算例没设预热且有两年以上时扣掉第一年；
  剩下满三年时末尾约 30%（整年，至少一年）作验证期。只填空着的框。
- 站点目标可写 `corrected: true`，Qle/Qh 改用 `Qle_cor`/`Qh_cor`；观测文件没有订正版时该目标失败，
  不退回未订正观测。格点产品、水文站目标不接受此项。
- 验证只用于留出诊断，不参与候选可行性、DE 选择或最佳候选排名；验证目标失败或支持集不可比时显示原因及空验证分数，不用剩余目标重算部分验证均分。

## 多站点语义

- **共享参数**：一个候选向量同时用于全部站点；每个站点仍是独立 member/site 任务。所有站点必须支持所选参数和目标。
- **站点独立**：为每个站点创建独立 Study，不把不同站点的参数拼成一个隐式层级模型。
  **GUI 目前只建共享参数研究**（规格写死 `site_mode: "shared"`）；站点独立只能用 CLI 手写规格。
  下面两条描述的是计划中的 GUI 行为，尚未实现。
- GUI 先对全部独立 spec 做无副作用预检，所有站点都通过后才创建目录，避免在后一个站点失败时留下半批 Study。
- baseline 数等于站点数；候选任务数为 `站点数 × 候选数`。界面在开始前显示三阶段的确切任务数。未有 baseline 实测时长或单算例产物大小时，不猜测时间或磁盘数值。
- 多个站点独立 Study 使用同一个 GUI 并发上限：最多同时运行 `jobs` 个 Study，每个 Study 内只使用 1 个 worker，避免变成 `jobs²` 个模型进程。
- GUI 和 CLI 都会把 `jobs` 限制在本机可用逻辑 CPU 数之内；CLI 的限制是最终安全边界。

## 冻结模型修订与旧程序

- 研究冻结了模型修订时，建研究用当前程序，**运行交给该修订自己缓存的 `colm-cli`**。研究设定是 `deny_unknown_fields`，所以修订的代码早于某个新设定时，它读不了这份设定。
- 建研究时先让修订的程序预检准备好的设定：只是不认得 `include_baseline` 就去掉它再试（这是增强项，不改研究含义）；不认得 Morris、`corrected`、不确定性分析的目标等设定时，拒绝建研究并说明原因。
- 运行时的选择不进研究设定，单独记在研究目录里：`model-version.json`（模型版本）、`run-options.json`（第一次运行时的引擎与前处理；之后沿用，明确要另一种就拒绝）。
- 已知问题：参数来源哈希（`parameter_source_sha256`）由建研究的程序按它自己编进去的 vendor 文件计算，修订的程序运行时用的是它自己那份。两者的 vendor 文件不同（如 10/21 上午冻结的修订）时，运行报 "Study parameter source files changed"。修法要让建研究和运行用同一个程序，尚未做。

## 暂停、恢复与失败

- 暂停只停止派发新任务，正在运行的模型正常结束。
- 停止后续任务把 Pending/Queued 标为 Cancelled，不强杀当前 Fortran 进程。
- 单个任务失败不取消其他任务；缺目标的候选保持具名 infeasible 状态。
- 重启时只有在进程身份可验证为已退出时才重排。无法验证的运行中任务进入 `NeedsReview`，避免双跑和同时写同一输出。
- 调度事件持久写入 `study.log`；模型原始输出仍留在每个任务的阶段日志中，避免重复写入总日志。
- 每个 Study 同时只允许一个调度器写入；`run.lock` 阻止终端和 GUI 重复启动同一 Study。
- `NeedsReview` 任务只能在用户确认原进程已退出后重试；重试会清理旧的进程身份、阶段和分数。
- DE 已完成选择的历史代不能重试，避免重写分数却不重放历史选择；需要重新评估时创建新 Study。暂停恢复复用未完成代的固定样本，等分替换不算停止条件中的改善。

## 结果与导出

- 不确定性：集合摘要、P05/P50/P95 与 `n_eff`、OAT 上下界有限差分斜率或 average-rank Spearman、分页成员表和解释警告。
- 某时刻 `n_eff < 20` 或低于成功集合数的 80% 时，对应 P05/P50/P95 写为 `null` 并记录持久警告，不绘制不稳定分位带。
- 参数调优：baseline/最佳候选校准与验证分、参数差异、固定目标明细、预算/代进度、失败原因和过拟合警告。
- 最佳候选某个参数归一化后离抽样边界不到 2% 时记 `bound: <参数> lower|upper <值>` 警告（网络权重不报），
  提示放宽范围重跑。
- GUI 写回草稿前比较所选成员与 baseline：率定期不更好、或验证期变差时按钮灰掉并说明原因，
  用户对该成员明确勾"仍要写入"才放开。
- 导出包括 manifest、扁平 samples.csv、metrics.csv、objectives.csv、失败表、Markdown 和可打印 HTML。PDF 使用系统打印“保存为 PDF”，不伪装成后台直接生成。
- 导出目标必须为空目录，或是同一 Study 的已有快照；拒绝覆盖无关目录及受管符号链接。重复导出替换结果快照，不残留旧结果。

### Morris 筛选

- `method: "morris"`，`budget.candidate_count` 是**轨迹数** r（缺省 10，至少 2），成员数 r·(k+1)。
- 网格 p = 4 层、步长 Δ = 2/3（按整数层号走，不在浮点上判断出界）；每条轨迹的基点从四层里抽，参数按随机次序各改一次 ±Δ。对数参数在对数空间里走。某点违反跨字段约束时整条轨迹按确定序号重抽，最多 1000 次。
- 基本效应 EE = Δy / Δu（u 为归一化位置）；`importance.json` 每个参数给 μ*（`value`，排序用）、μ（带符号，看方向）、σ（样本标准差）与有效步数 `n`。缺响应值的那一步跳过，不让整个参数没结果。
- GUI 把三种方法换成可比的"影响"：Morris 取 μ*，LHS 取 |ρ|，OAT 取 |斜率 × 抽样范围|。

V1 不包含 Sobol、贝叶斯优化、结构方案枚举、HPC 后端或直接强杀进程；这些只有在真实预算与使用证据表明当前能力不足时再增加。

## 当前能力矩阵（2026-10-29）

| 能力 | 状态 | 说明 |
|---|---|---|
| 单点 OAT / LHS / Morris 不确定性 | 支持 | 观测目标可选；`importance.json` 按响应量排序 |
| 单点差分进化率定（训练期选择 + 验证期比较） | 支持 | 验证期分数不参与选优；候选与基线核对观测支持集 |
| 格点算例率定（格点产品 / 区域通量站 / 水文站） | 支持 | 只配格内观测；无重叠明确拒绝，报告空间覆盖比例 |
| 格点算例不确定性（含空间目标） | 支持 | 与率定同一目标函数；月均聚合对通量站生效 |
| 日/月/年聚合的观测覆盖率 | 支持 | 分母来自完整时间轴/冻结输出频率，缺测不会抬高覆盖率 |
| 派生研究（敏感性→率定、派生设计记录 parent_study） | 支持 | 继承模型修订、算例、观测、目标、权重、聚合与时间窗；表达不了的组合明确拒绝 |
| AI 两步拟合（特征→参数网络） | 支持 | 特征来自研究冻结输入；留一研究交叉验证可判读；无验证时只能存为"未验证实验版本" |
| DE 直接训练网络并写回版本 | 支持 | 按产物类型导入参数/网络/联合，草稿审阅后冻结 |
| 远程研究提交与取回 | 支持 | 所有观测源随研究上传或按映射；率定/不确定性按类型核验取回 |
| 远程取回后写回版本 | 支持 | 在原始输出所在地（服务器）核验成员：作业/成员/结果树/样本/取回证据，不下载整份 history |
| 远程提前失败（构建/建研究/成员失败）恢复 | 支持 | 状态分类 + 权限矩阵 + 中英下一步：看日志/取回诊断/归档关闭/修复后重提 |
| 研究取消身份 | 支持 | 每次运行一个运行 ID，外层/内层 CLI 共用；按进程组 + 锁持有者补杀（校验可执行文件名），收尾按 ID 认锁 |
| 冻结代码修订的研究创建/预检 | 支持 | 由将要运行它的那份 CLI 执行，参数来源哈希与运行时一致 |
| 远程总核数/并发/每候选线程 | 支持 | 默认总核数 = 每候选线程 × 并发；显式 `--cpus` 必须 ≥ 每候选线程 × 并发（否则调度器覆盖不了实际并行），多申请允许 |
| 严格独立验证（留站/留年/留气候区分折训练） | 未提供 | 现有"留一站"仅为重排诊断 |
| 多目标/Pareto、按站点/年份/气候区汇总 | 未提供 | 目标权重可设，但结果是单一加权目标函数 |
| 全球大网格的流式评价/资源预算统一 | 未提供 | 空间评价先读整块变量；远程总核数分配待统一 |
