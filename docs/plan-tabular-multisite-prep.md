# CSV/TXT 多站点前处理计划

## 目标

前处理接受三类输入，而下游始终只接收标准的单站点 NetCDF：

1. 一份既有单站点 NetCDF；
2. 一份只含一个站点的 CSV/TXT；
3. 一份带站点标识列、包含多个站点的长表 CSV/TXT。

表格导入按站点拆分，每个站点写入独立的暂存强迫场。随后逐站点复用现有
缺测诊断、短缺口插值、ERA5-Land 订正和 QC 记录，不另造一套修复算法。

## 表格契约

- 首个非空、非 `#` 注释行是表头；UTF-8 BOM 会被移除。
- 自动识别逗号、制表符、分号或空白分隔；CSV 支持双引号和 `""` 转义。
- 长表可提供 `site` / `site_id` / `station` / `station_id`；没有时以文件名
  作为单站点名称。
- 时间支持 `YYYY-MM-DD HH:MM[:SS]`、ISO `T`、斜杠日期、12/14 位紧凑时间，
  以及 `Z` / `+08:00` / `-0500` 偏移。无偏移时按“人工值 → 偏移列 → 经度
  推断”解释，并在产物中统一写成 UTC。
- 经纬度、UTC 偏移和地类在同一站点内必须一致；不一致直接报出站点与字段。
- 空字符串、`NA`、`N/A`、`NaN`、`null`、`-9999` 作为缺测。缺失整条时间记录
  时，按该站点的主时间步补一条全缺测记录，不对观测值做重采样。
- 变量列和单位必须由用户确认。表头可用 `Tair[K]` 或 `Tair (K)` 携带单位。

## 产物与批量流程

1. 表格按站点拆到 `<Forcing>/.colm-tabular/<站点>_Met.nc`；
2. 每份暂存文件运行缺测诊断；
3. 只有短缺口时直接修复；有长/边界缺口时逐站点定位并复用或下载 ERA5-Land；
4. 最终文件写为 `<Forcing>/<站点>_Met.nc`，原表格和暂存文件不覆盖；
5. 如果表格提供经纬度，可同时在 `Sitedata` 目录批量生成 `<站点>_site.nc`；
6. GUI 汇报每站点的行数、补入的缺失时间步、缺测量、ERA5 需求和最终路径。

## 验收矩阵

- CSV 双引号、TSV、分号与空白 TXT 均能探测；
- 单站点无站点列时使用文件名；
- 多站点长表拆为独立文件，互不混入；
- ISO 显式偏移和经度推断均正确换算到 UTC；
- 缺失时间行被补成缺测值，交给现有修复层；
- 重复时间、站点内经纬度冲突、未知单位、同名文件冲突均阻断；
- 17 类 IGBP / 24 类 USGS 地类值保持为整数，不从经纬度猜测；
- GUI 与 sidecar 参数有静态回归测试，三平台 CI 通过。
